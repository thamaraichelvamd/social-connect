# SocialConnect
SocialConnect is a PHP-based social media platform developed as a college project. It allows users to connect through posts and interact with content.

## Technologies Used
- PHP
- MySQL
- HTML and CSS
- JavaScript
- XAMPP for local development

## Main Features
- User registration and login
- Create and view posts
- Like posts
- Browse posts by category
- View featured and trending posts

## Purpose
The goal of this project is to practise web development, database connectivity, and user authentication while building a functional social media application.

## Run Locally
1. Install XAMPP.
2. Place the project folder inside `htdocs`.
3. Start Apache and MySQL.
4. Import `database.sql` using phpMyAdmin.
5. Configure the database settings in `config/database.php`.
6. Open the project in your browser through `localhost`.

*Note: Features may vary depending on the current project implementation.*
